# 用户面板（`/panel`）

面向拿到站点账号的人：自己管密钥、看用量、查审计、改密码。全部操作都在浏览器里完成，不需要站长介入。

> 需要账号的 `channel=web`（面板账号）。`channel=api` 的账号只能用 API，登面板会被挡掉。

---

## 1. 注册与登录

| 动作 | 接口 | 说明 |
|---|---|---|
| 注册 | `POST /api/auth/register` | 用户名 3–32 位、密码 ≥8 位；受站点 `allow_register` 开关控制 |
| 登录 | `POST /api/auth/login` | 成功后下发 `rh_session` Cookie（HttpOnly，默认 7 天） |
| 退出 | `POST /api/auth/logout` | 只作废当前会话 |

注册会**自动发一把 API Key**（名为 `user-账号名`），面板里能看到尾 4 位。

---

## 2. 我的密钥

一人可持有多把，最多 20 把。每把独立配置：

| 字段 | 含义 | 取值 |
|---|---|---|
| 名称 | 按用途自己起 | 必填 |
| 额度(tokens) | 这把 key 最多能用多少（输入+输出合计） | 0 = 不限 |
| 有效期 | 多少天后失效 | 0 = 永久 |
| 模型限制 | 只允许调用这些模型 | 逗号分隔；留空 = 不限 |
| IP 白名单 | 只接受这些来源 | 一行一个，支持 CIDR；留空 = 不限 |
| 允许自查 | 这把 key 能否查 `/v1/usage` | 默认开 |

| 动作 | 接口 |
|---|---|
| 列表 | `GET /api/user/tokens` |
| 新建 | `POST /api/user/tokens` |
| 修改（启用/额度/模型/IP/有效期） | `POST /api/user/tokens/update` |
| 删除 | `POST /api/user/tokens/delete` |

**安全边界**

- 明文只在创建时返回一次，列表只回尾 4 位（`…f4d9`）。
- 只能操作自己 `user_id` 的密钥；别人的 id 与不存在的 id 都返回 404，不泄露存在性。
- 额度用尽或过期后请求被拒（403），凭证本身仍有效——不需要重发密钥，改额度即可。

---

## 3. 用量与余额

| 动作 | 接口 | 说明 |
|---|---|---|
| 账户概览 | `GET /api/user/me` | 余额、分组、角色、密钥列表、可用模型、最近消费 |
| 各客户端用量 | `GET /api/user/usage?days=7` | 按设备聚合：请求数、tokens、扣点 |
| 令牌自查 | `GET /v1/usage`（带 Bearer key） | 给程序用的：用户余额 + 令牌额度剩余 |

---

## 4. 使用日志（筛选 / 导出）

`GET /api/user/logs?days=7&model=&status=ok|fail&format=csv`

- 只包含**本人密钥**产生的调用，按令牌名集合判定，看不到别人的量。
- `days` 取值 1–90；`format=csv` 直接下载，带 BOM，Excel 打开中文不乱码。
- 面板上点「筛选」按条件加载，点「导出 CSV」拿全量。

---

## 5. 审计日志

`GET /api/user/audit?limit=100`

记录本人相关的操作：登录、登出、密钥增删改、改密码、邮箱绑定、兑换。**只有自己的**——全站审计在管理面，用户面板看不到别人的登录记录。

用途：出问题时自己先查「我的账号是不是被人动过」，而不是直接来问站长。

---

## 6. 账户安全

| 动作 | 接口 | 行为 |
|---|---|---|
| 改密码 | `POST /api/user/password` | 验证原密码 → 改新密码 → **踢掉本会话之外的所有会话** |
| 退出其他设备 | `POST /api/user/sessions/revoke` | 只踢别人，本会话保留 |
| 绑定邮箱 | `POST /api/user/email` | 需密码确认；仅记录，用于联系与人工找回 |

### 关于邮箱与找回密码（重要）

本站**默认没有接入邮件服务**，因此：

- 绑定邮箱 = 给站长一个联系你的方式，以及人工找回时的凭据；
- 面板不会发验证邮件，也不假装"已验证"；
- 忘记密码的正确路径是**联系站长重置**（站长执行 `relayhub.gateway users reset-password`）。

如果你自己部署并配置了 SMTP，才能启用自动找回；当前开源版本未实现这条链路。

## 7. 兑换码

`POST /api/user/redeem` `{"code": "..."}` — 兑换成功即时到账，记入审计。

## 9. 常见问题

**调用返回 401** — 密钥错、被删、已过期。面板「我的密钥」里看状态。

**调用返回 403「额度已用尽」** — 这把 key 的 token 额度用完。提高额度或换一把。

**调用返回 403「不允许从 x.x.x.x 访问」** — 命中 IP 白名单限制。改白名单或换出口 IP。

**`/v1/usage` 返回 403「不允许自查用量」** — 创建时关掉了「允许自查」。在面板改回。

**模型调用说「不存在」** — 可能被令牌的模型限制挡掉了，或该模型不在你的分组里。

**改完密码其他设备还能用？** — 正常情况下不能：改密码会即时作废其他会话。若仍可用，检查是否用的是 API Key 而不是面板登录（API Key 不受密码影响，需单独删除）。
