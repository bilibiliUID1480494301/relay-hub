relay-hub

LLM 网关。把 OpenAI、Anthropic、Gemini 三种协议互相转换，外加用户额度与按 token 计费。
纯 Python 标准库，不依赖任何第三方包。PyPI · GitHub

装和跑

pip install hubrelay

relayhub.gateway users init --username admin   # 密码只打印一次
relayhub.gateway serve  --port 8799  --pool pool.json
relayhub.gateway admin  --port 18802 --token 你定的口令

管理面在 localhost:18802，加完上游渠道就可以转发。不带 --pool 会走演示池，只够验证连通性。

curl localhost:8799/v1/chat/completions \
  -H "Authorization: Bearer sk-xxx" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"你好"}]}'

端点

路径协议
/v1/chat/completionsOpenAI Chat（含流式）
/v1/responsesOpenAI Responses
/v1/messagesAnthropic Messages（含 tool_use / stream）
/v1beta/models/{model}:generateContentGemini 原生（含 :streamGenerateContent）
/v1/embeddingsOpenAI Embeddings
/healthz探活，免凭证

上游侧按渠道配 anthropic-messages / openai-chat / gemini-api，进来的协议由网关转过去。

计费

cost = 未命中输入×单价 + 命中缓存×单价×折扣率 + 输出×单价 + 按次
     × 分组倍率 × 时段倍率
  • 峰谷按配置的时区算（默认 Asia/Shanghai），不看服务器本地时间
  • 时段规则表：星期 + 小时区间 + 节假日，顺序匹配，第一条命中生效
  • 按次收费可以和 token 计价叠加
  • 缓存命中（cache_read）与缓存写入（cache_creation）各自可独立定价：可配绝对单价，也可配相对输入价的比例。优先级：渠道绝对价 > 站点绝对价 > 比例折算。常见配置：DeepSeek 命中 0.1×、OpenAI 命中 0.5×、Anthropic 写入 1.25×。
  • quota = -1 的账号不参与计费

几条实话

  • 模型不在网关里跑，推理发生在上游。但推理开关会跟着协议转换：OpenAI 的 reasoning_effort 和 Anthropic 的 thinking.budget_tokens 互相对应，不会被静默丢掉。
  • 单进程多线程模型。并发压满时先加实例，前面挂一层反向代理做分发。
  • 不用 Redis 也不用数据库，所以多实例之间不共享内存态（会话、失败计数各自独立）。
  • 令牌和接入凭据只存哈希，明文只在创建时返回一次，找不回来就重发。
  • 请求正文不落盘。日志只有模型、token 数、耗时、状态码。
  • 「哪个客户端在调」这种数据只有用户本人能看，站长最多看到按用户的汇总。

不想装东西的话

没有 Redis、没有数据库、没有 Node 构建链。配置就是几个 JSON 文件，放在 %LOCALAPPDATA% 或 $XDG_DATA_HOME 下的 relay-hub 目录，换机器拷过去就行。
